# Formatador de Agenda

Ferramenta em HTML e JavaScript para processamento de agendas jurídicas exportadas do EasyJur.

## Funcionalidades

- Geração de Agenda Geral
- Separação por Área
- Separação por Tipo
- Geração de Agenda de Fatais
- Auditoria das alterações realizadas
- Exportação de Auditoria.xlsx
- Exportação de Resumo_Processamento.txt
- Exportação final em arquivo ZIP

## Tecnologias

- HTML
- JavaScript
- ExcelJS
- JSZip

## Como utilizar

1. Abra o arquivo index.html
2. Selecione a planilha exportada do EasyJur
3. Informe a data D0
4. Clique em "Gerar planilhas"
5. Baixe o ZIP gerado
